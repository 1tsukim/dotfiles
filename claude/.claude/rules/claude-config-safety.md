# ~/.claude/ 配下の改変ルール（自主規制）

`~/.claude/hooks/` 配下のファイル、`~/.claude/settings.json`、
および `~/.claude/CLAUDE.md` 自身は **ユーザーから明示的な指示があったときだけ** 編集する。

- 「hook が邪魔だから一時退避」「設定を変えれば速くなる」のような **自発的な判断で改変しない**
- hook が作業をブロックしたら、まずユーザーに状況を報告して **指示を仰ぐ**（勝手に hook を `.off` 化したり、`chmod -x` したりしない）
- 「hook を書き換えて」「settings に X を追加して」「permissions.deny に Y を入れて」のような **明示指示** があれば実行する
- 改変前に **影響範囲**（防御が一時的に低下する、別のコマンドが通らなくなる等）を一言で伝える
- 改変後に **復元の手順**（バックアップ場所、戻し方）を提示する

なぜ重要か: hook と settings は Claude Code 全体の安全装置。Claude が自発判断で書き換えると、防御層が抜けて誤操作の損害が拡大する。
